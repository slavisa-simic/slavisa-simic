# GitHub profile override

These page rules override the generated MASTER.md because the product is a GitHub README, not a newsletter, app, or React Native screen.

- Use native GitHub Markdown for all prose, links, captions, activity, and expandable details. No newsletter form, subscriber claim, custom CSS UI, or oversized raster page.
- Header: only the preserved S mark is an image. Name, role, shell prompt, and contacts are native selectable HTML/Markdown using samp. Use a restrained terminal theme without a fake terminal screenshot, SVG text, blinking cursor, or fake runtime telemetry.
- Projects: one centered carousel with a smooth horizontal transition between the two projects. The entire carousel links to the visible Projects list below; each list entry opens that project's README from its beginning.
- Use the supplied official project logos as exact source files. Crop transparent margins and resize proportionally; preserve their colors, shapes, lettering, and detail. The Potamorph artwork is the requested official brand asset even though its imagery differs from the restrained page styling.
- Self-contained SVG translation provides smooth motion and lossless logo images. Hold each project for three seconds and transition in 400 ms. With reduced motion, switch projects every three seconds without positional movement. The explicit static preview is inside Project notes. Never silently replace the requested carousel with a PNG based on motion preference.
- Terminal layout: native command-style headings, real text, small cached Shields.io badges, and an API-generated repository table. Keep Codex under AI Development Tools, and leave project notes and raw commit messages behind disclosures.
- Potamorph demonstrates AI-assisted development with OpenAI Codex. Unity/C# are project implementation details, not personal skills.
- Retain Inter for authored images and GitHub's native body typography. Names and essential labels remain legible on 320 px screens; body text stays native at 16 px.
- Project blue and muted red identify the projects; preserve actual source artwork. No armor or technology tree.
- Each carousel card must have its own project identity above a shared footer. Vigil uses a light blue engineering/blueprint surface; Potamorph uses a darker teal/rust identity. Both explicitly show the project name, a short description, and the unchanged official logo. The Explore projects footer stays common across cards.
- Keep all links keyboard accessible and the carousel target larger than 44 px. Reduced motion removes sliding and typing while retaining the requested three-second content changes. A fully static preview is available on demand.
- Statistics are native selectable table values from GitHub's API, automatically synced hourly. Include per-repository 30-day commit counts, stars, and a timestamp for the last successful fetch. Exclude profile automation. Never replace the requested stats with a static chart image.
- A successful fetch updates the last-sync time even if counts are unchanged; failed fetches retain all previous content. No rankings, fictional statuses, invented achievements, or project languages presented as personal expertise.
